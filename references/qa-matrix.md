# 验收矩阵

以原始细节查看成图。所有必需维度都必须通过。

| 维度 | 通过条件 | 阻塞失败 |
| --- | --- | --- |
| 背景 | 所有非人物区域保持全彩真实照片，并保留原图几何、光线与纹理 | 出现全局插画化、纸张化、黑白化或描边处理 |
| 数量 | 只有指定人物发生变化；其他人物、吉祥物与物体保持原数量和媒介 | 主体被新增、删除、合并或误转换 |
| 原图锚点 | 姿态、发型、服装轮廓、配饰与手持物仍可辨认 | 重要原图锚点被删除、替换或虚构 |
| 发型整理 | 头发长度、分缝或刘海方向、束发或披发结构仍可辨认；杂乱飞发被合并成清晰黑色发块，并保留少量有意图的发束 | 逐根描摹杂乱发丝、意外秃发缺口、尖刺发团、头盔式发型、虚构刘海、替换发型或增加过多发量 |
| 人物比例 | 可见头部与脸部宽度、肩膀、躯干、四肢、服装体积和透视遵循原图轮廓 | 脸更宽或更圆、头部放大、身体拓宽、四肢缩短、服装膨胀或幼化 |
| 姿态与遮挡 | 位置、大小、动作、站姿、接触点和前后层级与原图一致 | 人物变大、虚构躯干或四肢、接触点悬空 |
| 人物感觉 | 明显可爱、简洁、手工绘制，同时保留原人物的成人体型 | 通过拓宽、膨胀、缩短或幼化制造可爱感；变成僵硬时装插画或纤细编辑线稿 |
| 墨线语法 | 粗糙厚轮廓、暖白纸张填充、纯黑头发或深色块，内部标记极少 | 漫画细线、复杂衣褶、逐根发丝、排线或空洞剪影 |
| 五官 | 友好的极简五官：优先两个小圆点与一条平静或略带友好感的短嘴；合适时使用放松的闭眼弧线或省略五官 | 紧绷或皱眉表情、五官位置不自然、大眼睛、肖像式绘制、写实瞳孔、鼻子或嘴唇、睫毛、瘦脸或面部阴影 |
| 色彩点缀 | 不使用点缀，或只保留一个原图已有的小配饰颜色 | 虚构颜色、多个点缀或为了装饰给整件衣服上色 |
| 文字 | 默认不添加任何可读文字 | 出现标题、标签、伪文字、水印或界面 |
| 技术 | 比例与尺寸符合要求；原图保留；最终文件非破坏性保存 | 比例错误、覆盖原图或最终文件缺失 |

背景、原图锚点、姿态与遮挡或固定人物感觉任一失败时，立即拒绝成图。更写实的五官永远不能作为重试方案。

## 用户明确通过的特征

`assets/accepted/` 中的四张样片覆盖以下情况：

- 近距离自拍：保持原图脸宽与肩宽；黑色头发、暖白外套和深色肩带简洁且可辨认；
- 与吉祥物合影：浅色连衣裙保持暖白；手持深色衣物保持黑色；橙色手机是唯一彩色点缀；动作准确保留；
- 长椅遮挡：黑色外套与浅色长裤区分清楚；长椅保持真实照片并位于人物前方；
- 栏杆重叠：栏杆保持真实照片，并保留原有前后关系。

这些样片只能用于视觉验收，绝不能作为生成输入。
